# Cloud Hopper

The personal portfolio site for Neeshal Imrit. It is a lightweight, dependency-free static site with:

- A recruiter-focused introduction and contact CTAs
- Responsive editorial layouts for work, background, and skills
- An animated CSS rabbit hopping across a cloud
- The “Cloud Hopper” riddle and cloud-computing story
- Small interactive work-card status messages

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server.

The site is intentionally built with plain HTML, CSS, and JavaScript so it can be deployed to any static host.
